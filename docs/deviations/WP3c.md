# WP3c deviations (assets, licences, dev packs)

Owned and delivered: `xtask/src/{assets, licenses, dev_packs}.rs`, `xtask/assets.lock`,
`xtask/tests/assets_{fetch, licenses}.rs`, `src/lib/about/thirdparty.json` (content). Generated by the package's commands
and committed with it: `public/fonts/KFGQPC-Hafs-V30.LICENSE.txt` (§4.7 step 2; the TTF itself stays gitignored).

## Deviations from ARCHITECTURE.md

1. **`thirdparty.json` shape** (the spec names only the file, and WP0D created it as `[]`). It is an object, so each
   licence text is stored once and packages refer to it by index:
   ```ts
   interface ThirdParty {
     /** Sorted by ecosystem (cargo, then npm), name (case-insensitive) and version. */
     packages: ThirdPartyPackage[]
     /** Licence/notice text segments, each stored once; see `texts` below. */
     texts: string[]
   }
   interface ThirdPartyPackage {
     ecosystem: 'cargo' | 'npm'
     name: string
     version: string
     /** Declared licence as a normalised SPDX expression ("MIT/Apache-2.0" → "MIT OR Apache-2.0"). */
     licence: string
     /** The alternative the app uses ("MIT" for "MIT OR Apache-2.0"; "MIT AND Unicode-3.0" for a conjunction). */
     used: string
     /** Repository, else homepage, else the crates.io/npmjs page. Always http(s). */
     url: string
     /** Declared authors, e-mail addresses removed (may be empty). */
     authors: string[]
     /** The package's licence text is `texts.map((i) => all.texts[i]).join('\n\n')`; empty = it ships no licence file
      *  (show `licence` and link `url`). */
     texts: number[]
   }
   ```
   A licence file is split into segments before the MIT grant paragraph ("Permission is hereby granted, free of
   charge…") and the OFL 1.1 title, and after Apache's "END OF TERMS AND CONDITIONS", and segments are shared when they
   are equal ignoring whitespace layout. So copyright lines stay with their package and the standard bodies are stored
   once (440 packages share one MIT body). Today: 520 crates + 52 npm packages, 282 segments (202 KB), 323,075 B in
   all (711 KB before the sharing). The file is rendered with one package or text per line (compact, still line-diffable), in a fixed order,
   with no paths, dates or host details. It is rewritten only when it changes.
2. **What is listed.**
   - Rust: the *normal* dependency closure of the app crate `quran-desktop`, from `cargo metadata --locked
     --filter-platform` for the four release targets (§13.4: `x86_64-pc-windows-msvc`, `x86_64-apple-darwin`,
     `aarch64-apple-darwin`, `x86_64-unknown-linux-gnu`). Build-script and dev-only crates are not shipped. Workspace
     crates are our own. Filtering by the release targets (not the host) makes the output identical on every OS, which
     the WP-CI drift check needs. Proc-macro crates are listed (conservative).
   - npm: `pnpm licenses list --json --prod` (the `dependencies` closure, including the three Fontsource font
     packages), plus each package's `package.json` for its repository and author.
3. **Licence policy gate (beyond the spec).** Every declared licence is parsed as an SPDX expression (legacy `/`
   accepted) and must be satisfiable with the allowed set: MIT, Apache-2.0 (also WITH an exception), BSD-2/3-Clause,
   ISC, Zlib, 0BSD, MIT-0, Unlicense, CC0-1.0, BSL-1.0, Unicode-3.0, Unicode-DFS-2016, CDLA-Permissive-2.0,
   BlueOak-1.0.0, NCSA, OpenSSL, Python-2.0, MPL-2.0, OFL-1.1, CC-BY-4.0, CC-BY-3.0. A GPL/LGPL/AGPL-only, unknown or
   missing licence fails `cargo xtask licenses` and lists every offender, so an unshippable dependency cannot slip in.
   For a choice, the alternative backed by a shipped licence file wins, then preference order; only the files of the
   used alternative are kept (`LICENSE-MIT`, not `LICENSE-APACHE`). Generic files (`LICENSE`, `COPYRIGHT`, `NOTICE`,
   `LICENSE-THIRD-PARTY`, `LICENSES/*`) are always kept.
4. **39 packages ship no licence file** in their published crate/tarball (the `objc2-*` family, `specta*`,
   `tauri-specta*`, `webview2-com*`, `dlopen2*`, `selectors`, `rusqlite_migration`, `realfft`, …). They are listed with
   `texts: []`; nothing is invented for them. The command prints them as a note.
5. **`fetch-assets` details.**
   - The TTF sits in a directory inside the zip (`KFGQPC-Hafs-V30/KFGQPC Hafs V30.ttf`, next to a `.docx`). It is found
     by file name in any directory, and exactly one such member must exist. Decompression is capped one byte past the
     expected size.
   - Offline fast path: when the local TTF matches its `assets.lock` pin, nothing is downloaded (the CI cache keyed by
     the lock's hash then never hits fonts.qurancomplex.gov.sa). The licence text is still regenerated from the TTF on
     every run, so it cannot drift from the shipped binary.
   - Every check (archive size 844,410 B, member size 301,356 B, pin, EULA present) runs before anything is written. A
     pin mismatch without `--force` writes nothing and says how to re-pin. A font without a licence (name ID 13) is
     refused.
   - `xtask/assets.lock` is TOML: a header comment, then one `[[asset]]` table per file with `file`, `source`, `bytes`
     and `sha256` (lowercase hex). It is validated on read (hex shape, no duplicates, no unknown keys). The pinned
     sha256 equals LEAD item 7 (`c9dd7e71…aeec47a`).
   - **`KFGQPC-Hafs-V30.LICENSE.txt` is now generated.** The header names the font (name IDs 4 and 5), the source URL,
     the size and sha256, and which name IDs are quoted. The licence follows verbatim (ID 0, then ID 13), with CR LF
     → LF and trailing spaces removed. The previous hand-written file had every line break doubled (CR and LF counted
     separately) and a download date, which made it non-reproducible. There is no date now.
6. **`fetch-dev-packs` details.**
   - It fetches exactly the `decor` pack's 3 files (§4.8), not `decor.nastaliq`, so the default run is 3 × 47 + 3 = 144
     files.
   - Mirrors are tried in catalog order, each with 3 attempts (0.5 s, 2 s back-off on transport errors, truncation,
     408/425/429/5xx), 8 downloads at a time, and every write is atomic.
   - A file is validated before it is written, and an existing file before it is kept. Page fonts are checked for the
     `wOF2` signature and for the WOFF2 header's own total length, which catches truncation without catalog sizes.
     Decor is checked for the catalog's exact size and sha256, plus the sfnt signature for the TTF. Valid files are not
     downloaded again; damaged ones are. `--force` re-downloads everything.
   - A failed file does not stop the others. The command lists every failure and exits non-zero.
7. **Shared helpers live in `assets.rs`** (`net::{runtime, client, get, Retry}`, `write_atomic`, `write_if_changed`,
   `read_optional`, `sha256_hex`, `rel_path`, `group`) and `dev_packs.rs` and `licenses.rs` use them. That avoids a
   fourth WP3c file.
8. **Tests**: `xtask/tests/assets_fetch.rs` (fetch-assets and fetch-dev-packs against an in-test HTTP/1.1 server; the
   dev-packs plan against the real catalog; a check that the committed licence text equals what the fetched font
   produces) and `xtask/tests/assets_licenses.rs` (SPDX, policy, file selection, segments, the cargo/pnpm readers on
   synthetic input, and a check of the committed `thirdparty.json`, including that it is byte-for-byte what
   `render()` produces). Like WP3a's tests, they compile `cli.rs` and the WP3c modules by `#[path]` (xtask is a binary
   crate). A one-line stand-in `mod fixtures { PAGES }` replaces the fixture exporters.
9. **Windows `pnpm`**: it is a `.cmd` shim, so `licenses` tries `pnpm.exe` and then `pnpm.cmd` (`pnpm` elsewhere).

## Data findings (handoff)

- **The two QCF page-font mirrors are not byte-identical.** On 2026-10-10 a full `--all-pages` run from the first
  mirror (`verses.quran.foundation`, which also matches `quran.com/fonts`) gave 1,815 files, all valid, in 25 s. Some
  pages differ in size from the QUL mirror (`static-cdn.tarteel.ai`):
  - v1: 1 page (p94);
  - v2: 2 pages (p72, p250);
  - v4 colrv1: 82 pages (e.g. p4, p153, p506).
  QF serves newer revisions. The research CSV (FACT §4.1) and the catalog `sizeBytes` match the QUL files.
  `catalog-check --online` compares only p1 and p604, which agree on both mirrors.
  - **WP5a:** exact QF totals are v1 47,949,744 B, v2 97,748,636 B and v4 50,878,540 B. The catalog has 47,952,076,
    97,748,500 and 50,877,636. Consider those numbers and a mirror-consistency note.
  - **WP5c:** a page fetched from the fallback mirror may be an older revision of the font. Glyph codes are
    unaffected as far as is known, but the bytes differ.
  - **WP8b:** measure glyph scale on QF-mirror files (what `fetch-dev-packs` downloads).
- Fixture pages (47 per variant) total v1 3,351,332 B, v2 6,543,632 B, v4 3,616,780 B, and decor 332,556 B (equal to the
  catalog).

## Requests

- **WP12c (About):** read `thirdparty.json` with the shape above. It is ≈ 320 KB, so load it lazily when the
  collapsible "Open-source licences" section opens, e.g. `const { default: notices } = await
  import('$lib/about/thirdparty.json')`. That keeps it out of the startup chunk; TypeScript infers the type from the
  file, and the interface above can be used for props. Join `texts` per package with a blank line and render it as
  plain text (`white-space: pre-wrap`), never as HTML. `url` is always http(s) and safe for `system_open_external`.
- **WP-CI:** the drift check is `cargo xtask licenses && git diff --exit-code src/lib/about/thirdparty.json`. It needs
  `pnpm install --frozen-lockfile` first. `cargo metadata` downloads the crate sources it reads licence files from,
  and the output is the same on every OS. Cache `public/fonts/` keyed by `hashFiles('xtask/assets.lock')`, then run
  `cargo xtask fetch-assets`: on a cache hit it verifies offline.
- **WP0D (`docs/DEVELOPING.md`):** the troubleshooting row for the missing Hafs TTF still says "WP3c; until it lands,
  copy the TTF into `public/fonts/` by hand". `pnpm assets` now works, and that clause can go.
- **Lead:** fold items 1–6 into §4.1/§4.7/§4.8 and §9.7 (the `thirdparty.json` shape), and the mirror finding into
  FACT §4.1.
